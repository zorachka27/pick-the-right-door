# Pick the Right Door!

A Roblox multiplayer survival game prototype for the concept you described. Players choose the correct door each round while surviving hardening rooms and traps. The longer a player survives, the more difficult the challenge becomes.

## Included in this prototype

- lobby and world environment
- challenge rooms with random themes
- door generation and timer flow
- safe door logic and wrong-door trap effects
- coin and progression tracking
- world unlock structure
- admin controls and event placeholders
- richer lobby polish with shop and event areas

## Key folders

- `src/ServerScriptService` — server logic, round flow, traps, progression, and admin tools
- `src/StarterPlayer/StarterPlayerScripts` — player HUD and in-game status updates
- `docs/GAME_DESIGN.md` — design overview for the full game
